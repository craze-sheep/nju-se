# 1.0

这是这个 coding agent 项目的 1.0 版本工作区。

这一版的目标很小：先把最简易的开发流程、需求、计划和开发记录整理出来，再实现一个不依赖现成 agent 框架、而是自己写循环和本地工具的命令行 agent。

## 这一版要做什么

- 让用户在终端进入交互式对话
- 调用 DeepSeek 原生 tool calling 决定下一步动作
- 通过本地工具搜索、读文件、写文件、运行命令
- 把工具结果再回传给模型
- 最后输出完成结果
- 可选打开 planner / reviewer 轻量分工，但 executor 仍是唯一执行者

## 这一版不做什么

- 不做网页界面
- 不做完整多智能体编队
- 不做长期记忆
- 不接现成 agent 框架 / SDK
- 不做复杂权限系统，只做会话级只读 / 可写切换
- 不追求功能很强，只追求最小闭环

## 当前状态

现在 1.0 已经接入了最小闭环的核心骨架：

- 命令行入口
- 环境变量读取
- DeepSeek 调用封装
- 本地搜索、文件和命令工具
- Agent 循环
- 可选 planner / reviewer 分工模式

运行时仍遵守题目要求：

- 不使用 agent 框架
- 不依赖服务端托管的代码执行或文件工具
- API key 只从环境变量读取
- 工具逻辑在本地自行实现
- 默认只读，需要时可用 `/access` 切到可写
- 小任务优先用 `search` 定位相关文件，再读取少量命中文件
- 输入 `/subagents` 可以打开或关闭轻量 subagent 分工；planner / reviewer 不带工具权限
- `run_command` 直接在当前工作区本地执行；危险命令会在执行前要求确认

启动后直接进入对话模式：

```bash
PYTHONPATH=1.0/src python -m nju_agent
```
