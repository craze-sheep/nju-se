# 1.0

这是这个 coding agent 项目的 1.0 版本工作区。

这一版的目标很小：先把最简易的开发流程、需求、计划和开发记录整理出来，再逐步实现一个能和大模型配合干活的命令行 agent。

## 这一版要做什么

- 让用户在终端输入一个编程任务
- 调用大模型决定下一步动作
- 通过本地工具读文件、写文件、运行命令
- 把工具结果再回传给模型
- 最后输出完成结果

## 这一版不做什么

- 不做网页界面
- 不做多智能体
- 不做长期记忆
- 不接复杂 agent 框架
- 不追求功能很强，只追求最小闭环

## 当前状态

现在 1.0 处于文档优先阶段。文档确定后，再开始写测试和实现。

建议开发顺序：

1. 先写需求
2. 再写计划
3. 再写测试
4. 最后写实现
5. 每一步都记录到 `doc/log.md`

## 建议的提交方式

